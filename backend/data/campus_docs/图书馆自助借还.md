# 图书馆自助借还

> 来源：阳光学院图书馆 · 自助服务
> 原文：https://lib.ygu.edu.cn/info/1045/3014.htm
> 抓取日期：2026-10-21｜官网发布：未标注
> 内容：自助借还机怎么用、有哪些注意事项

图书馆公共查询系统使用方法
 一、书目检索：输入要查询书目的题名，该系统即可检索到该书的具体信息：索书号、作者，出版社，是否可借等，读者可根据以上信息进书库找到该书的确切位置，进行借阅。
 二、登录“我的图书馆”这个模块，可以进行续借、预约，读者荐购等功能的操作，详细的登录方式，在进入“我的图书馆”这个页面后，屏幕的右方有详细提示，如用户名，初始密码等。
 三、温馨提示：“我的图书馆”操作完成后，一定要注销，否则别的用户能继续操作，给读者造成不必要的麻烦。
 RFID自助借还书系统使用方法
 一、借书操作步骤
 在屏幕点击“借书” →输入借书证号（23级学生借书证号即为学号，22级之前的为“S+学号”）→ 输入密码（学生初始密码为“身份证号后6位”，教师初始密码为“888888”）→ 选择借阅数量，再将图书书脊统一向下整齐放置于借/还书台上，核对屏幕信息 → 确认无误后点击“确认借阅” → 借书完成。
 二、还书操作步骤
 点击“还书” →将图书书脊统一向下整齐放置于借/还书台上，→核对屏幕信息→确认无误后点击“确认归还” →将所还图书放入旁边的书车里→还书完成。
 三、附录：借书证密码修改方法
 （一）在检索机上打开“图书馆v5.0书目检索系统”。
 （二）点击“我的图书馆”选项。
 （三）按屏幕上的提示在指定位置输入借书卡号、密码和验证码，并点击“登录”。
 （四）点击屏幕上的“修改密码”选项；按屏幕上的提示在指定位置输入原始密码和新密码（两次，注：新密码长度不得超过10个字符）
 （五）点击“确定”以完成密码修改。
