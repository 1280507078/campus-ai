# 图书馆借阅流程

纸质图书借阅流程
 读者进入书库后，可直接到书架前进行挑选，需要借阅的图书可直接拿到自助区域进行自助借阅（可参考RFID自助借还书系统使用方法）。
 工具书借阅流程
 一、根据工具书管理规定，该类图书不予借出阅览。
 二、如需要复印工具书内容，可将工具书和本人借阅证带到工具书室借阅台办理借阅证抵押手续后，方可将工具书带至图书馆复印区进行复印，并当班借当班还。
 三、复印完毕后，将工具书交至工具书室借阅台工作人员手中，待检查后方可退还借阅证。
 现报、现刊借阅流程
 一、根据期刊室管理规定，该类文献资料不予借出阅览。
 二、读者架前挑选期刊、报纸，阅览完毕后应将所阅文献资料放回所在架上。
 三、如需要复印期刊内容，可将期刊和本人借阅证带到期刊室借阅台办理借阅证抵押手续后，方可将期刊带至图书馆复印区进行复印；复印完毕后，将期刊交至期刊室借阅台工作人员手中，待检查后方可退还借阅证。
 四、现报、现刊需当班借当班还。
 光盘借阅流程
 一、携带光盘配套的纸质图书前往电子阅览室借阅处，将图书和借阅证一并交由电子阅览室工作人员。
 二、根据图书信息调出与之配套的光盘，做好相关信息登记后，将借阅证暂时抵押在该室，方可借出光盘。
 三、归还光盘时，将其交给该室工作人员，待检查无误后，方可换取借阅证。
 读者荐购流程
 一、单位荐购
 各系部、各单位根据各自教学、科研、工作需要，可向图书馆提交经由系、部主任审批同意的纸质购书报告。
 二、个人荐购
 （一）线上荐购
 读者可在阳光学院图书馆书目检索系统http://10.255.11.202:8080/opac/search_adv.php#/index中读者荐购模块填写相关荐购信息。
 （二）现场荐购
 读者可在图书馆服务台直接填写相关荐购信息后交至总服务台即可。
 （三）电子邮件荐购
 读者通过学院网站登录图书馆网页，在“帮助中心”模块中下载《阳光学院图书馆读者荐书登记表》，按表中提示填写荐购书目信息，并发送至图书馆指定邮箱：526290069@qq.com。
 （四）荐购处理
 图书馆会认真处理读者的荐购意见，无论荐购成功与否，都会给读者反馈；荐购图书到馆后，荐购人会在第一时间收到图书馆的借阅通知。
 图书馆研讨室使用申请流程及须知
 一、登陆i阳光服务平台，教务系统板块中的教室使用申请模块进行预约申请。
 二、研讨室仅限在校师生申请使用，申请人通过后，请至本馆二楼期刊室办理申请。
 三、本研讨室3人以上可申请使用，本馆研讨室使用人数最多8人。
 四、申请时间：周一至周日8:10-21:30；请提前一天申请预约，预约通过后在预约时段内准时使用，如需延期请在使用时段结束前提出申请，如其他读者已有预约申请则不可延期。
 五、申请者须服从管理人员的安排，自觉爱护公共设施和仪器设备，损坏物品须照价赔偿。
 图书馆影音鉴赏室使用申请流程及须知
 一、登陆i阳光服务平台，教务系统板块中的教室使用申请模块进行预约申请。
 二、申请时间：周一至周日8:10—21:30，活动筹备时间控制在3小时以内。
 三、使用部门须服从管理人员的安排，自觉爱护公共设施和仪器设备，如发生损坏须照价赔偿。
 四、使用部门举办活动时须有负责人在场，实行谁组织活动、谁负责安全工作的原则。
 图书馆多功能报告厅使用申请流程及须知
 一、报告厅主要用于学校举行的重大外事活动，学术报告，学术会议和工作会议，以及各二级院系、部处承办的全国性或区域性的学术会议和工作会议。
 二、凡需使用报告厅的单位或部门，应提通过i阳光服务平台中会议室申请模块提出申请。提出使用时应说明使用报告厅事由，活动名称，使用时间、参会人员名单、参会人数及会场设备要求等内容。办理使用手续后需要变更或取消使用计划的，须在预约使用日前一天通知图书馆办公室(电话：83969623)。
 三、报告厅音响、话筒、投影机和屏幕等设备由图书馆安排专人操作，其他人员不得擅自操作。除会场的固定设备和音响设备外，会议需要的其它设备由使用单位或部门自行解决。活动筹备时间控制在3小时。
 四、报告厅开放时间：周一至周日8:30-21:30（寒、暑假及国家法定假日，原则上不开放）。
 五、使用部门须服从管理人员的安排，自觉爱护公共设施和仪器设备，如发生损坏须照价赔偿。
 六、使用部门举办活动时须有负责人在场，实行谁组织活动、谁负责安全工作的原则。
 图书馆公共查询系统使用方法
 一、 书目检索：输入要查询书目的题名，该系统即可检索到该书的具体信息：索书号、作者，出版社，是否可借等，读者可根据以上信息进书库找到该书的确切位置，进行借阅。
 二、登录“我的图书馆”这个模块，可以进行续借、预约，读者荐购等功能的操作，详细的登录方式，在进入“我的图书馆”这个页面后，屏幕的右方有详细提示，如用户名，初始密码等。
 三、温馨提示：“我的图书馆”操作完成后，一定要注销，否则别的用户能继续操作，给读者造成不必要的麻烦。
 RFID自助借还书系统使用方法
 一、借书操作步骤
 在屏幕点击“借书” →输入借书证号（23级学生借书证号即为学号，22级之前的为“S+学号”）→ 输入密码（学生初始密码为“身份证号后6位”，教师初始密码为“888888”）→ 选择借阅数量，再将图书书脊统一向下整齐放置于借/还书台上，核对屏幕信息 → 确认无误后点击“确认借阅” → 借书完成。
 二、还书操作步骤
 点击“还书” → 将图书书脊统一向下整齐放置于借/还书台上， → 核对屏幕信息 → 确认无误后点击“确认归还” → 将所还图书放入旁边的书车里→还书完成。
 三、附录：借书证密码修改方法
 （一）在检索机上打开“图书馆v5.0书目检索系统”。
 （二）点击“我的图书馆”选项。
 （三）按屏幕上的提示在指定位置输入借书卡号、密码和验证码，并点击“登录”。
 （四）点击屏幕上的“修改密码”选项；按屏幕上的提示在指定位置输入原始密码和新密码（两次，注：新密码长度不得超过10个字符）
 （五）点击“确定”以完成密码修改。
