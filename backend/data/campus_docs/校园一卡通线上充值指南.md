校园一卡通线上
充值操作指南
(2024年11月)
亲爱的老师、同学们：
为提供更加便捷、安全的校园一卡通充值体验，我校一卡通线上充值服务将迎来重大调整！请注意以下重要变化：自11月30日起，“完美校园”APP内“去充值”通道将停用，统一使用“支付宝”APP“完美校园小程序”中的“工行聚合支付宝”充值通道。
具体操作步骤如下：
第一步：打开支付宝，搜索框输入“完美校园“
第二步：选择“完美校园”小程序，点击打开
第三步：点击“绑定校园卡”
第四步：填写“姓名”“卡号”“校园卡密码”
第五步：绑卡完成后，回到首页点击右上角的“充值”
第六步：输入金额后，选择“工行聚合支付宝”充值通道
