# 校园报修系统使用指南

升级啦
校园报修系统
校园报修无轻事
迅速响应保顺畅
为了持续优化校园生活的便捷性与舒适度
 我们的校园报修系统已全面升级
01
一键报修，高效响应
快来动动手指，下载“完美校园”，点点点，进入“报修系统”，填一填，提交吧！维修师傅立马get到你的呼唤，飞速赶来！‍确保问题得到及时响应与处理。
扫一扫下载完美校园
登录后选择“全部应用”-“校园生活”-“报修系统”
点击填单报修，按要求填写报修内容，点击提交报修
02
透明流程，全程跟踪
想知道维修进度？简单！维修过程中的每一个环节，我们都将为你提供详细的进度反馈。您可以在系统中实时查看维修师傅的接单到完成关键节点信息，维修过程一目了然，超透明！
选择“报修单”，可以查看进展和详情
同时，为了更好地满足您的需求，我们提供了便捷的沟通渠道。你可以直接在系统中与维修师傅进行文字或电话交流，需求说明白，情况问清楚，沟通零障碍！
03
评价反馈，持续改进
修好了？别忘了给师傅点赞或提建议哦！在“待评价”里，动动手指，留下你的反馈，你的每一条意见都是我们前进的动力，将帮助我们不断优化服务流程，提升服务质量。
在“报修单”-“待评价”找到工单，填写服务评价
04
疑问解答，随时在线
旧系统同步停用，如对于升级后的系统使用或其他疑问，可以通过校园管理处24小时热线（校本部：18059166101；滨海校区：15359193725）进行咨询，校管处及物业服务单位将共同保障维修工作的及时响应，共同助力校园后勤保障工作高效开展。
