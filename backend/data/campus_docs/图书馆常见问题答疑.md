# 图书馆常见问题答疑

> 来源：阳光学院图书馆 · 帮助指南
> 原文：https://lib.ygu.edu.cn/info/1075/2663.htm
> 抓取日期：2026-10-21｜官网发布：未标注
> 内容：借书证密码、自助借还、WIFI、开水房、物品清理等读者高频问题

Q:读者出入图书馆要刷卡吗？
A:读者入馆时从南面正门经刷卡通道刷卡入馆，出馆时须从入馆右侧边出馆门禁通道离馆。
Q:我的借书证号和密码是什么？
A: 23级学生借书证号即为学号 (22级之前的借书证号为“S+学号”)，初始密码均为“身份证后6位”。
如果更改过密码后忘记密码，请本人携带身份证原件到图书馆一楼总服务台进行密码重置。
Q:RFID自助借还书系统使用方法？
A: （1）借书操作步骤
在屏幕点击“借书” →输入借书证号（学生借书证号为学号）→ 输入密码（学生初始密码为“身份证号后6位”，教师初始密码为“888888”）→ 选择借阅数量，再将图书书脊统一向下整齐放置于借/还书台上，核对屏幕信息 → 确认无误后点击“确认借阅” → 借书完成。
（2）还书操作步骤
点击“还书” → 将图书书脊统一向下整齐放置于借/还书台上， → 核对屏幕信息 → 确认无误后点击“确认归还” → 将所还图书放入旁边的书车里→还书完成。
Q:读者在自助借还机上办理图书借、归还手续，由于操作不当导致的图书丢失需要赔偿或逾期需要缴纳滞纳金，由谁承担后果？
A: 读者在自助借/还时应认真核对图书信息、数量，出现操作不当导致图书丢失和逾期缴纳滞纳金的后果由读者本人承担。
Q:读者离馆时可以把个人物品放在阅览座位上吗？
A: 不可以。图书馆每晚在闭馆时都会对阅览桌椅（备考加油站除外）进行清理，个人物品一律收走，图书馆不负责保管，如出现个人物品遗失现象由读者本人承担后果。
Q:图书馆的开水房分布在哪里？
A: 图书馆二楼、三楼和四楼安全通道口各有一间开水房。
Q:如何使用图书馆WIFI？
A: 1.开启WLAN，连接Yango-University；
2.若浏览器没有自动跳转至“校园网准入身份系统”，请打开任意网址（如百度www.baidu.com）即可跳转谁页面；
3.进入“校园网准入身份系统”登录页面后，输入用户名和密码进行登录认证；
注：教职工—用户名：工号
初始密码：身份证后8位
学 生—用户名：学号
初始密码：18位身份证号
请及时修改密码，并绑定邮箱（邮箱可用于找回密码）。如果未绑定邮箱忘记密码，请求助辅导员联系信息化处沈老师办理重置密码手续。（PS：阳光学院VPN暂时只对教工开放，未对学生开放）
Q:什么是图书书标？图书书标的作用是什么？
A: 书标是用于记录图书分类排架号（索书号），粘贴于图书书脊的下部的标签，由字母和数字组成分为两行；书标上的图书分类信息可作为图书分库排架、读者查找图书的依据。
Q:什么是索书号？
A: 索书号是图书馆馆藏书排架和读者检索、查找图书的依据，一个索书号代表一种图书，打印在书标上，贴在每本书书脊的下部。索书号由两部分组成：分类号和著者号。分类号是根据图书的学科主题所取用的分类号码，索书号是按照图书作者姓名所编排的著者号码。
Q:如何利用联机公共书目查询系统查找馆藏资源？
A: 在图书检索机上点击“阳光学院图书馆书目检索系统“，或网页搜索图书馆官网，点击“馆藏目录”进入书目检索系统（目前检索系统仅支持在校内网使用），输入检索词（如题名、著者、出版社等），在检索结果中选择，点击选中结果，查询出该种图书的馆藏信息，读者可根据索书号到对应的书库里查找图书。
Q:读者可以向图书馆推荐征订图书吗？
A: 可以。
荐购方法：登陆图书馆网站，点击“图书荐购”→进入阳光学院图书馆书目检索系统→登录“我的图书馆”→点击“读者荐购”→填写荐购图书信息（需要读者邮箱绑定验证,图书荐购信息与图书馆的反馈信息都通过绑定的邮箱进行传递）。
Q:如何使用中国知网的资源？如何使用福建省高校数字图书馆（fulink）资源？
A:上网认证后，登录图书馆网站，进入数据库导航模块，进入知网，即可检索、下载文章。福建省高校数字图书馆（fulink）的利用则在图书馆主页有“FuLink”标识的检索框内输入检索词，检索结果将通过绑定的邮箱进行传递，24小时文献传递最大篇幅为50页。
Q:电子阅览室电脑异常重启后，为什么文件找不到了？
A: 为了防止电脑病毒传播，电子阅览室电脑安装有还原系统，电脑重启开机后，所有硬盘信息恢复为原始数据，建议有文件操作需求的直接在u盘上操作，以免机器故障导致文件丢失。
Q:如何借阅图书书后光盘？
A: 携带本人学生证和所要借阅书后光盘的图书，至图书馆二楼电子阅览室办理光盘借阅登记。
Q:图书馆报告厅、研讨室、影音鉴赏室如何申请？
A: 图书馆报告厅、研讨室和影音鉴赏室，均可通过i阳光平台申请。其中，报告厅只用于会议、报告、讲座之用，目前仅限教职工申请。研讨室和影音鉴赏室所有人员均可申请，每次使用人数不得少于3人，且使用时限为3个小时。
Q:期刊是否可以借阅？
A: 期刊室内的未装订的现刊和现报、工具书一律不外借，仅供在期刊阅览室内阅览。装订好的过刊、过报合订本，可以到图书馆二楼期刊室查找借阅。
Q:装订好的期刊合订本何时可以借阅？
A: 由于期刊具有时效性，无法当期分散征订，现刊需提供读者阅览，所以期刊室统一在年底整理、装订期刊，正常情况下一年可借阅前一年的期刊合订本。
Q:如何检索所需要的期刊？
A: 在“阳光学院图书书目检索系统“上检索是否有馆藏，然后到期刊室根据书架目录，快速查找到所需刊物；或直接到期刊室咨询。
Q:期刊室的现刊、现报、工具书可以暂借出去复印吗？
A: 现刊和现报可暂借复印，读者需携带学生证到期刊室工作台办理相关手续后方可借出，但必须当班借当班还；工具书由于价格贵重，只可阅览不可带出复印。
Q:备考加油站申请对象？
A: 大三、大四备战考试的学生。
Q:备考加油站申请时间？
A: 每年开学初，具体时间请关注阳光学院图书馆网站、图书馆微信公众号或者各二级院系通知。
Q:备考加油站申请方式？
A: 如有需申请专座的学生，可在一站式平台中登入自己学号进行申请。流程如下：
登入一站式服务平台→选择“图书馆预约服务”模块→选择“专座申请”模块→点击“申请”功能→填写个人信息→辅导员审批。
一站式平台会通过摇号的方式进行抽取，同时随机分配座位。
Q:备考加油站使用期限？
A: 通过摇号方式获得的专座可使用到当年12月31日。
Q:备考加油站有考勤要求吗？
A: 有。要求 “周出勤时数≥30小时”。
Q:违反备考加油站使用要求有处罚吗？
A: 有。累计违规三次，则取消座位使用权。
Q:备考加油站因退座或因违规被清退而空出的座位如何处理？
A: 本着合理流通，循环使用的原则，凡在使用期间违规被清退或不再需要专座而退出来的座位通过摇号的方式进行替补，替补的名单将发布在我馆官网和官微上，并通知所在学院。
Q:查找图书时，图书是如何按索书号排序的？
A: 图书遵循书架“从上到下，从左到右”、走“S”型路线的原则，根据索书号（分类号+著者号）从左向右逐位比对，“-”和“#”右侧、“()”内整体比对。
分类号：1.首字母：英文26字母顺序，2.数字部分：逐位比对、从小到大，3.符号：“-”>“()”>“=”>“:”
著者号：1.先数字后字母，2.符号：“#”>“()”>“=”，3.以“(英)”、“(日)”等起始的入外文库
