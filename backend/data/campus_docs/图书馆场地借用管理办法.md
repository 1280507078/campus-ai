# 图书馆场地借用管理办法

> 来源：阳光学院图书馆 · 规章制度
> 原文：https://lib.ygu.edu.cn/info/1066/3170.htm
> 抓取日期：2026-10-21｜官网发布：未标注
> 内容：班级/社团借用图书馆场地怎么办

为了保障图书馆资源的合理利用和环境的整洁有序，特制定本管理办法。本办法适用于所有申请和使用图书馆场地的单位和个人。
 一、场地借用流程
 申请：借用者需通过一站式平台提交场地借用申请，明确借用时间、活动性质等详细信息。
 审批：图书馆管理员将根据场地使用情况和活动性质，决定是否批准借用申请。审批结果将在申请提交后的2个工作日内反馈给申请者。
 确认：借用申请获批后，借用者需签署借用协议，并遵守图书馆的所有规定。
 二、使用规范与责任
 秩序维护：借用者应确保活动期间场地秩序，禁止任何妨碍图书馆正常运作和其他用户权益的行为。
 场地复位：活动结束后，借用者必须立即清理场地，恢复到借用前状态，包括排列座椅、清理垃圾等。
 损害赔偿：对于借用期间造成的任何损害，借用者需负责赔偿。
 三、违规处理
 如借用后未能按要求整理复位的单位或个人，将受到以下处罚：
 首次违规：一周内禁止借用任何图书馆场地，并进行通报，提交书面说明并承诺不再发生类似情况。
 重复违规：一个月内禁止借用任何图书馆场地，并需进行面谈，明确后续改进措施。
 第三次及以上违规：取消其当学期内的借用资格，并视情况报告相关学院或部门进行进一步处理。对于反复违规的单位或个人，图书馆管理部门有权增加其后续借用审批的难度或要求，直至取消其借用资格。
 四、附则
 1、本管理办法由图书馆负责解释。
 2、本管理办法自发布之日起实施，如有修改，按新的管理办法执行。
