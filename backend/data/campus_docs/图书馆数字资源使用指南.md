# 图书馆数字资源使用指南

> 来源：阳光学院图书馆 · 自助服务
> 原文：https://lib.ygu.edu.cn/info/1045/3167.htm
> 抓取日期：2026-10-21｜官网发布：未标注
> 内容：校外怎么访问数据库、知网怎么用

——数字资源介绍——
 图书馆目前购买的数字资源有中国知网（www.cnki.net），超星汇雅电子图书（www.sslibrary.com），Fulink文献提供系统（www.fulink.edu.cn），FuLink学科服务平台（xk.fulink.edu.cn），Fulink书后光盘管理系统（discx.yuntu.io）。
 一、中国知网（www.cnki.net）
 我校自2018年开始购买中国知网的中国学术期刊网络出版总库、中国博士学位论文全文数据库、中国优秀硕士学位论文全文数据库、中国重要会议论文全文数据库、中国重要报纸全文数据库、中国法律知识资源总库等6个子库，目前累计有学位论文1543792册，期刊26263册。
 二、超星汇雅电子图书（www.sslibrary.com）
 我校目前以远程包库的形式购买的超星汇雅电子图书有130万册，由于版权问题，图书会不定时更新。同时，在图书馆一楼大厅，配有超星歌德电子图书阅读机，含有图书3000种，每月更新150种，需读者用学习通扫码阅读。
 三、Fulink文献提供系统（www.fulink.edu.cn）
 “福建省高校数字图书馆（FULink）”是经教育厅批准，由“福州地区大学新校区文献信息资源共享平台（FULink）”扩展而成的，目前FULink已扩容至全省92所院校，并在该范围内实现相互开放、联合保障。

 ——中国知网操作指引——
 以下简单介绍下中国知网的数据库如何使用。
 Step1:
 校园网内打开中国知网首页，默认在上方偏右位置有“阳光学院”的登录信息，此时即可在检索框中检索所需文献。
 Step2:
 排除不能自动登录原因（系统问题、浏览器问题）。这时可手动登录，点右上方“登录”，然后点击“IP登录”，即可登录成功。
 Step3:
 检索举例：以关键字“教育”为例进行检索，就可以搜索到相关的文献信息。在右边有下载图标，表示此文章可以下载，默认下载的文件为CAJ格式的。此格式文献需配合CAJViewer浏览器才能打开。如需PDF格式文件，需点开文献“题名”，进入详情也下方有PDF下载的链接。部分文献右方不是下载图标，而是一个锁的图标，说明此文献不在我校购买的包库范围内，故不能下载。
 ——超星汇雅电子图书操作指引——
 Step1:
 打开超星汇雅电子图书首页，在右上方显示有“阳光学院的用户”，说明已在校园网内登录，并能查询、检索所需电子图书。
 Step2:
 例如检索：一地霜白。点击图书详情，即可看到图书信息，以及多种阅读模式。有适合在移动设备上阅读的EPUB阅读和扫码阅读模式（可安装超星学习通扫码，并不是所有图书都有此类模式）；有可在网页上直接阅读的图像阅读模式；还可在首页下载安装超星阅读器客户端，注册登录个人账户后下载图书。
 ——Fulink操作指引——
 Fulink包括三个数据库：Fulink文献提供系统、FuLink学科服务平台、Fulink书后光盘管理系统。
 Fulink文献提供系统（www.fulink.edu.cn）：
 校园网内打开fulink主页，可直接搜索中外文资源。以关键字“金融”为例，进行检索，在每条检索记录下方有“获取：电子全文，文献传递”的链接，点击“电子全文”即可跳转我们购买的中国知网的相关页面直接下载，点击“文献传递”可跳转文献传递页面，输入读者的邮箱和验证码后，6小时之内即可获取文献。“文献传递”功能也可传递图书，但是需分多次进行传递。同时，读者邮箱中收到的链接也具有一定的时效性。
 FuLink学科服务平台（xk.fulink.edu.cn）
 通过Fulink学科服务平台，读者也可检索相关文献，但是文献资源相对fulink文献提供系统会少一些，特别是外文资源。但是在学科服务平台上，可创建读者个人的“学科空间”、“研究空间”等，检索方法与Fulink文献提供系统类似，通过校园网检索，在检索条目下方有各个数据库的链接，同时也可进行文献传递。
 注意事项：学科服务平台具有账号自动漫游功能。建议读者通过手机号、邮箱注册个人账户，详细填写学校、读者证号、身份类型等信息后，登录使用。在校园网登录一次，即可在外网漫游使用一年。
 Fulink书后光盘管理系统（discx.yuntu.io）
 读者可在Fulink光盘管理系统中，检索书后光盘的资源，可下载解压后使用。检索关键字可以是图书书名或者图书的ISBN号。
