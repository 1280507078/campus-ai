# 后勤工作职责

> 来源：阳光学院后勤基建处
> 原文：https://sbc.ygu.edu.cn/gzzz.htm
> 抓取日期：2026-10-21｜官网发布：未标注
> 内容：后勤管哪些事、哪些不归它管

后勤基建处是对学校的教学、办公、生活等运营活动提供所需场所及相关设备、设施、水电等配套资源，并代表学校行使相关管理职能以保证上述资源得以有效、合规利用的后勤保障部门。主要职责如下：
（一）依据学校发展战略和学科建设规划，制定校园建设规划。
（二）制定学校后勤保障工作计划，编制学年财务预算。
（三）协同相关职能部门实施校园建设项目，组织建设工程的验收与评估。
（四）负责行政办公室、学生公寓和教师宿舍的调配与管理。
（五）保障学校水、电、网等基础设施正常运行，对计划外的断水、断电采取有效应对措施以减少其负面影响。
（六）负责学校教学、办公、生活设备、设施的维护、维修工作。组织行政办公设备报废、更新的技术鉴定工作，协调跨部门设备调剂和资源共享工作。
（七）负责校园环境及楼内公共区域的绿化和保洁管理工作。
（八）负责保障学校教学工作具备良好的设施与环境。
（九）代表学校负责进行后勤服务社会化相关事务（包括物业、绿化、通勤车辆）的管理，以确保其所提供的服务质量。
（十）负责学校土地、房屋等不动产和设备、家具等固定资产盘点工作，负责学校行政办公低值物品和耗材等物品的保障；负责组织学校资产清查工作，做好校产报废核销工作。
（十一）为学校各类大型活动提供后勤保障。
（十二）负责制定食堂管理制度，对食堂运营进行监督管理。
（十三）负责制定学校招商需求，开展商户管理。
（十四）协助监督部门和职能部门处理质疑和投诉。
