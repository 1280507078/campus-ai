换了新包之后，先确认「跑的是新包」（重要）：
  1) 启动时看横幅里的 Package build，应当等于本清单第 5 行的构建号。
     若不是（或弹出向上找目录的警告），说明启动脚本用的是旧文件夹：
     关掉所有窗口 -> 把旧文件夹整个删掉 -> 重新解压到全新的路径。
  2) 登录页页脚显示「后端构建 …」，应与上面的构建号一致。
  3) 浏览器打开 http://127.0.0.1:8000/api/ping 也能看到同一个号。

放到服务器 / 云平台上跑（可选）：
  服务读 PORT 环境变量（顺序 CAMPUS_API_PORT -> PORT -> API_PORT），
  并监听 0.0.0.0，所以云平台直接 python backend/main.py 就能起；
  只有**一个**端口，前端由后端在 /app 下一起托管，不需要另外起静态服务。
  页面经 https 访问时前端以同源方式调用 /api，不会拼出 http:// 而触发混合内容拦截。

安装后确认依赖完整：
  双击 check-windows.bat，看第 5 项 Backend dependencies
  显示 ALL OK 表示依赖完整；显示 MISSING 则重新运行 start-windows.bat

导入课表只需要 xlrd + openpyxl，不需要 pandas。
