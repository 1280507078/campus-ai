启动脚本说明
============================================================

本目录提供两个脚本，双击运行：

  start.bat   一键启动（后端 + 前端 + 打开浏览器）
  check.bat   环境诊断（只查看信息，不启动任何服务）

文件名与内容使用英文的原因
------------------------------------------------------------
其一：脚本中断
.bat 文件如果包含中文，一旦文件编码和 Windows 控制台代码页
对不上，中文会显示为乱码，脚本随即中断（表现为
窗口一闪即关）。

其二：依赖安装失败
backend\requirements.txt 也不能有中文。pip 读这个文件时用的是
系统默认编码（中文 Windows 上是 cp936/GBK），如果文件是 UTF-8
并且含中文，会直接报错：
  UnicodeDecodeError: 'gbk' codec can't decode byte 0xab ...
因此 requirements.txt 内的注释全部使用英文。

结论：两个 .bat 与 requirements.txt 均使用纯
ASCII，在任何 Windows 环境下都不会出现乱码。

使用步骤
------------------------------------------------------------
1. 双击 start.bat 即可，放置位置不限。

   脚本会自动向上查找项目根目录（同时含有 backend 和
   frontend 的那个文件夹），最多向上查找 4 层。
   以下位置均可正常工作：
     - 项目根目录（和 backend、frontend 同级）
     - 根目录下的 启动工具 文件夹
     - 启动工具下面再建的子文件夹（最多 4 层内）

   如果脚本报 "Project root : NOT FOUND"，说明脚本距项目根目录
   超过 4 层，移入项目文件夹后重新运行即可。

2. 首次运行如果提示缺少依赖，按屏幕提示先在命令行执行：
     cd /d "<项目目录>\backend"
     python -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
   装完再双击 start.bat

出问题怎么办
------------------------------------------------------------
双击 check.bat，将屏幕内容截图即可定位问题。

手动启动（备用方案）
------------------------------------------------------------
  cd /d <项目目录>\backend
  python -m uvicorn main:app --reload --port 8000

  （另开一个命令行窗口）
  cd /d <项目目录>\frontend
  python -m http.server 5500

然后浏览器打开 http://127.0.0.1:5500/login.html
